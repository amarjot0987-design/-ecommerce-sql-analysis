# 🛒 E-Commerce Sales Analysis — SQL Project

## 📌 Project Overview
End-to-end SQL analysis of an e-commerce platform's order data covering **revenue performance, customer behavior, product trends, and city-wise insights** using MySQL.

---

## 🎯 Business Questions Answered
| # | Question |
|---|---|
| 1 | What is the overall business performance? |
| 2 | Which product category drives the most revenue? |
| 3 | Which are the top 5 best-selling products? |
| 4 | Is revenue growing month over month? |
| 5 | Who are the highest-value customers? |
| 6 | Which cities contribute the most revenue? |
| 7 | Which payment method do customers prefer? |
| 8 | How many customers are repeat buyers? |
| 9 | What is the cumulative revenue trend? |
| 10 | Which orders are above average order value? |
| 11 | Which categories perform above average? |

---

## 🛠️ Tools & Concepts Used
- **Tool:** MySQL + MySQL Workbench
- **Concepts:** JOINs, GROUP BY, Subqueries, CTEs, Window Functions (RANK, SUM OVER), CASE statements, Aggregate Functions, DATE_FORMAT

## 📊 Key Findings
- **Electronics** is the highest revenue category contributing ~70%+ of total sales
- **Laptops** are the top-selling product by revenue
- **Delhi** is the highest revenue-generating city
- **Credit Card & UPI** are the most preferred payment methods
- Repeat customers account for a significant share of total orders

---

## 🚀 How to Run
1. Install MySQL + MySQL Workbench
2. Open `ecommerce_analysis.sql` in MySQL Workbench
3. Run the full file using `Ctrl + Shift + Enter`
4. View results section by section
